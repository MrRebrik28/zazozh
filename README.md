# Моё восстановление 🌸

Бережный персональный веб-трекер реабилитации, самочувствия, активности и привычек.
Работает как автономное **PWA-приложение** (с возможностью установки на экран «Домой» на iPhone и Android), так и в качестве **Telegram Mini App**.

---

## 🌟 Основные возможности

1. **Главный экран («Сегодня»)**:
   - Ежедневный чек-ин самочувствия: настроение, сон (в часах), уровень энергии (1–10), боль (0–10) с выбором зон дискомфорта (шея, плечи, поясница, суставы, голова, мышцы).
   - Интерактивные цели дня с чекбоксами (сохраняются отдельно для каждого дня).
   - Трекер заботы: водный баланс (8 стаканов в 1 клик) и отметка приёма витаминов/лекарств.
   - Копилка маленьких побед и благодарностей себе.
   - Прогресс за последние 7 дней (скользящее недельное окно).

2. **Интерактивный календарь**:
   - Месячная сетка с цветными точками активности (чек-ин, тренировка, вес).
   - Просмотр и редактирование записей за любой прошедший день.

3. **Комплексы и ЛФК**:
   - Выбор комфортных упражнений + возможность добавлять свои собственные упражнения.
   - Встроенный таймер отдыха и мягкого дыхания (1, 2, 3, 5 минут).
   - Сохранение истории тренировок с комментариями о самочувствии.

4. **Динамика и графики**:
   - Фиксация веса.
   - Высокочёткий Retina-график с поддержкой переключения метрик: **Вес**, **Сон**, **Уровень боли**.
   - Фильтрация периодов: 7 дней, 30 дней, 90 дней, всё время.
   - Расчёт минимума, максимума и динамики изменений.

5. **Замеры тела**:
   - Талия, бёдра, бедро, обхват груди, плечо/рука + заметка.

6. **Паспорт и приватность**:
   - 100% локальное хранение данных в **IndexedDB** браузера с fallback на **LocalStorage**.
   - Экспорт и импорт резервных копий (полная обратная совместимость с версиями v1 и v2).
   - Генератор сводки для лечащего врача или реабилитолога в один клик.

7. **Мобильная адаптация и эстетика**:
   - Бережная палитра в пудровых пастельных тонах.
   - Мягкая тёмная тема для вечернего времени.
   - Нижняя панель навигации (Bottom Navigation) с поддержкой safe-area iPhone (Dynamic Island / челка).
   - Поддержка тактильного отклика (Haptic Feedback) в Telegram и на мобильных устройствах.
   - 100% оффлайн-режим через Service Worker.

## 🚀 Быстрый старт

### Установка зависимостей
```bash
npm install
```

### Запуск локального сервера разработки
```bash
npm run dev
```
Приложение откроется по адресу `http://localhost:3000`.

### Запуск тестов
```bash
npm test
```

### Сборка для продакшена
```bash
npm run build
```
Собранные оптимизированные файлы попадут в папку `dist/`.

## 🌐 Бесплатный хостинг и деплой

### Вариант 1: GitHub Pages (автоматически)
В репозитории уже настроен GitHub Actions workflow (`.github/workflows/deploy.yml`).
1. Создайте репозиторий на GitHub и привяжите удалённый адрес:
   ```bash
   git remote add origin https://github.com/ВАШ_ЛОГИН/zazozh.git
   git push -u origin main
   ```
2. В настройках репозитория на GitHub перейдите в **Settings → Pages** и в качестве источника выберите **GitHub Actions**.
3. При каждом пуше в ветку `main` проект автоматически тестируется, собирается и публикуется на бесплатном домене вида `https://ВАШ_ЛОГИН.github.io/zazozh/`.

### Вариант 2: Cloudflare Pages
1. **Через CLI**:
   ```bash
   npx wrangler login
   npm run deploy:cf
   ```
2. **Либо через панель Cloudflare**:
   - Зайдите на [dash.cloudflare.com](https://dash.cloudflare.com/) → **Workers & Pages** → **Create application** → **Pages** → **Connect to Git**.
   - Выберите репозиторий `zazozh`.
   - Команда сборки: `npm run build`, папка вывода: `dist`.
   - Cloudflare предоставит бесплатный адрес `https://zazozh.pages.dev` с мгновенным CDN и SSL.

## 🤖 Запуск как Telegram Mini App

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram.
2. Создайте бота (`/newbot`) или выберите существующего.
3. Отправьте команду `/newapp`, выберите бота и укажите URL вашего развёрнутого сайта (из GitHub Pages или Cloudflare Pages).
4. Теперь приложение открывается прямо внутри Telegram в виде нативного всплывающего окна с тактильной отдачей и автоматической адаптацией темы!
